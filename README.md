# rag__project
Praxisprojekt: RAG-System zur Beantwortung von Fragen über nachhaltige Mode 

## Voraussetzungen

* Python 3.x
* Ollama installiert (https://ollama.com)

## Setup

1. Installieren Sie Ollama

2. Modell starten:
   ollama run llama3

3. Abhängigkeiten installieren:
   pip install sentence-transformers faiss-cpu numpy requests

4. Projekt starten:
   python rag.py
